# أسئلة مباشرة

الجمهور يمسح رمز QR، يكتب سؤاله من الموبايل، والسؤال يظهر فوراً على شاشة العرض.

## الصفحات
- `/` صفحة الجمهور: كتابة السؤال (اسم اختياري).
- `/screen` شاشة العرض: السؤال الأحدث بخط كبير، والباقي تحته، ورمز QR على الجنب.
- `/screen?key=مفتاحك` نفس الشاشة مع أزرار "اعرضه كبير" و"حذف" (لك أنت فقط).

## النشر على Render (مجاني، رابط دائم)
1. أنشئ حساب على github.com وارفع محتوى هذا المجلد لمستودع جديد (Repository).
2. أنشئ حساب على render.com واختر New + ثم Web Service، واربطه بالمستودع.
3. الإعدادات: Runtime = Node، Build Command = `npm install`، Start Command = `npm start`، Instance Type = Free.
4. من Environment أضف متغير `ADMIN_KEY` وقيمته كلمة سر طويلة من اختيارك.
5. بعد النشر بياخد رابط مثل `https://qa-live-xxxx.onrender.com`. هذا هو رابطك الدائم، ورمز QR على الشاشة بيتولّد تلقائياً منه.

## ملاحظات مهمة
- الخطة المجانية بتنام بعد حوالي 15 دقيقة بدون زوار. افتح `/screen` قبل الفعالية بخمس دقائق عشان يصحى.
- الأسئلة بتنحفظ بملف على الخادم، وبتروح لو أعاد Render تشغيل الخدمة أو نشرت نسخة جديدة. للفعاليات القصيرة هذا كافي.
- لو بدك اسم نطاق خاص (مثل `ask.example.com`) ضيفه من إعدادات Custom Domains في Render، ووقتها ضيف متغير `PUBLIC_URL` بنفس الرابط.
- حماية بسيطة: سؤال واحد كل 5 ثواني لكل جهاز، وحد أقصى 300 حرف.

## تشغيل محلي للتجربة
```
npm install
ADMIN_KEY=123 npm start
```
ثم افتح `http://localhost:3000/screen`.
